# Bulls Lab Frontend

This project is built with Vite and React, using Tailwind CSS for styling.

## Prerequisites

- **Node.js**: Requires version `^20.19.0` or `>=22.12.0`.
  - If you use `nvm`, you can switch to the latest LTS version:
    ```bash
    nvm use --lts
    ```

## Installation

Install the project dependencies using npm:

```bash
npm install
```

## Development

To start the local development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173/`.
